Terms of Service

Effective Date: September 2026 · Developer Fair Use

1. Service Provision

ImageEngine provides an open, keyless SVG rasterization API to web developers, open-source projects, and media platforms. The service is provided "as is" with high-availability edge caching across global data centers.

2. Developer Quota & Fair Use

  • Monthly Cold Renders: Up to 500,000 uncached renders per month. Cached edge hits do not count toward this limit.
  • Bandwidth Allocation: 100 GB monthly outbound bandwidth.
  • Payload Limit: Input SVG files must not exceed 512 KB in uncompressed XML text.
  • Dimensions: Supported width range is between 100 px and 2400 px.

3. Intellectual Property

Users retain full ownership and copyright of all SVG graphics, vector paths, and typography submitted to the API. ImageEngine asserts zero ownership claims over generated raster assets.

4. Rate Limiting & Protection

To preserve sub-20ms responsiveness for all developers, ImageEngine reserves the right to throttle abusive bots or IP addresses engaging in denial-of-service attempts.
