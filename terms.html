Effective Date: September 2026 · Last Updated: September 2026

1. Service Provision

ImageEngine provides a free, high-performance edge image rasterization API for web developers, designers, open-source maintainers, and digital publishers. The service is provided on an "as is" and "as available" basis without express warranties of 100% uninterrupted availability.

2. Developer Fair Use & Quota Allocation

ImageEngine operates on an open, keyless model supported by global edge caching. To guarantee high availability and low latency for all users, the following service quotas apply:

  • Monthly Cold Renders: Up to 500,000 uncached image generation calls per month across public workloads.
  • Bandwidth Allowance: Up to 100 GB of egress image transfer per month.
  • Dimension Boundaries: Allowed width ranges between 100px and 2,400px. Standard social cards should use the default 1200px width.
  • Maximum SVG Payload: Ingested SVG files must not exceed 512 KB in uncompressed XML markup.
  • Global Edge Caching: All generated assets are cached for up to 1 year at the edge layer. Cached requests do not consume your compute quota.

  • Bypass rate controls or interfere with edge network integrity.
