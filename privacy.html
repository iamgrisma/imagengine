Privacy Policy

Effective Date: September 2026 · Operational Architecture

1. Core Privacy Philosophy

ImageEngine is intentionally engineered as a stateless, ephemeral microservice. We have no interest in tracking developers, profiling visitors, or harvesting media assets.

2. What We Never Collect

  • No Tracking Cookies or Sessions: No analytics cookies, advertising pixels, or session identifiers.
  • No Permanent Storage of Images: SVGs are decoded in volatile RAM and immediately flushed after rasterization.
  • No Personal Identifiable Information (PII): No names, email addresses, or phone numbers are requested or recorded.

3. Transient Memory Processing

When an SVG URL is passed via ?url=... or submitted via POST body, the payload is parsed strictly in volatile serverless memory. Once the raster binary buffer is dispatched to the client, the memory buffer is cleared. No files are written to server hard drives or permanent databases.

4. Edge Caching Layer

To minimize latency and network overhead, rendered raster images are stored across shared CDN edge nodes using standard HTTP Cache-Control headers. These caches store only the public rendered image binary.

5. Contact

Questions regarding data handling or security can be directed via grisma.com.np.
