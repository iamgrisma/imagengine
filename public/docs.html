API Reference

ImageEngine converts dynamic or static SVG graphics into high-resolution PNG, JPG, or WebP images at global edge speed. No API key required — just construct a URL and use it.

Base URL

https://imagengine.grisma.com.np/api

All requests are served over HTTPS. Both GET and POST methods are supported.

GET /api

Renders and returns an image binary directly with standard Content-Type headers. Response is a raw image file — use it directly in <img> tags, og:image meta tags, or download via cURL.

GET https://imagengine.grisma.com.np/api?url={ENCODED_SVG_URL}&format={png|jpg|webp}&width=1200

POST /api

Send raw SVG markup in the request body. The API will detect the SVG content and rasterize it. Useful for dynamically generated SVGs that don't have a public URL.

POST https://imagengine.grisma.com.np/api?format=png&width=1200
Content-Type: text/plain

<svg width="1200" height="630" xmlns="http://www.w3.org/2000/svg">
  ...your SVG content...
</svg>

Query Parameters

Parameter Type Default Description
url string — Full URL of the source SVG to fetch and rasterize. Must be URL-encoded.
format string png Output format: png, jpg (or jpeg), webp.
width number 1200 Output width in pixels (100 — 2400). Aspect ratio is strictly preserved.
quality number 85 Compression quality for jpg and webp (10 — 100). Ignored for PNG.
Built-in Card Generator
title string — Headline text for the built-in OG card generator. Triggers card mode.
subtitle string — Secondary description text below the title.
badge string — Small pill badge label shown above the title.

Response

Status Content-Type Description
200 image/png, image/jpeg, image/webp Raw image binary. Use directly in <img> or <meta> tags.
400 application/json Invalid or missing SVG payload.
502 application/json Failed to fetch SVG from the provided source URL.
500 application/json Internal rendering error.

Integration Examples

1. HTML Open Graph Tag (WhatsApp, Facebook, LinkedIn)

<meta property="og:image" content="https://imagengine.grisma.com.np/api?title=My+Page+Title&subtitle=Description+here&format=png" />
<meta property="og:image:width" content="1200" />
<meta property="og:image:height" content="630" />
<meta property="og:image:type" content="image/png" />

2. Twitter/X Card

<meta name="twitter:card" content="summary_large_image" />
<meta name="twitter:image" content="https://imagengine.grisma.com.np/api?title=My+Page&format=png" />

3. Remote SVG Conversion

<meta property="og:image" content="https://imagengine.grisma.com.np/api?url=https%3A%2F%2Fyour-site.com%2Fog.svg&format=png" />

4. cURL

curl -o preview.png "https://imagengine.grisma.com.np/api?title=Hello+World&format=png"

5. JavaScript / React / Next.js / Astro

export function getOgImageUrl(title, subtitle) {
  const base = 'https://imagengine.grisma.com.np/api';
  const params = new URLSearchParams({ title, subtitle, format: 'png', width: '1200' });
  return `${base}?${params.toString()}`;
}

// Usage in <head>:
// <meta property="og:image" content={getOgImageUrl('My Page', 'Page description')} />

6. POST Raw SVG (cURL)

curl -X POST -d '<svg width="1200" height="630">...</svg>' \
  "https://imagengine.grisma.com.np/api?format=webp&width=800" \
  -o output.webp

Cached image requests are served from the edge and do not count against the monthly render quota. Most production workloads stay well under limits.

Multi-Tier Edge CDN Caching

Every response dispatches full RFC-standard and platform-specific edge caching headers: 

Cache-Control: public, max-age=31536000, s-maxage=31536000, stale-while-revalidate=604800, stale-if-error=86400
CDN-Cache-Control: public, max-age=31536000, stale-while-revalidate=604800
Vercel-CDN-Cache-Control: public, max-age=31536000, stale-while-revalidate=604800
Cloudflare-CDN-Cache-Control: public, max-age=31536000, stale-while-revalidate=604800
ETag: "..."

Images are cached globally for up to 1 year. Conditional GET requests with If-None-Match automatically return 304 Not Modified with zero payload bandwidth.

CORS Policy

The API sends Access-Control-Allow-Origin: * on all responses. You can call the API from any domain, browser application, or serverless worker without cross-origin blocks.

🛡️ Firewall & Cloudflare WAF Whitelisting

When using ?url=https://..., ImageEngine makes an upstream HTTP request to fetch your SVG. If your origin domain is protected by Cloudflare Bot Fight Mode, AWS WAF, or strict rate limits, the request may be flagged as automated traffic and blocked with a 403 Forbidden or challenge page.

Outgoing User-Agent:

User-Agent: ImageEngine/1.0 (+https://imagengine.grisma.com.np)

Cloudflare WAF Skip Rule Configuration:

To ensure reliable image generation, add a custom rule in your Cloudflare dashboard (Security → WAF → Custom rules):

Rule Name: Allow ImageEngine SVG Fetcher
Field: User Agent
Operator: contains
Value: ImageEngine
Action: Skip → WAF Managed Rules, Bot Fight Mode, Rate Limiting
