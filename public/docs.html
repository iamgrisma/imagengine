API REFERENCE · v1.0

ImageEngine API Reference

ImageEngine is a high-performance, keyless edge microservice engineered to rasterize vector SVG graphics into production-ready PNG, JPG, and WebP images with sub-20ms latency and 1-year multi-tier global edge caching.

🌐 Base URL

All API endpoints are served over strict TLS/HTTPS with global CORS enabled:

https://imagengine.grisma.info.np/api
GET

/api

Converts an upstream SVG URL or dynamically renders a branded Open Graph card using query parameters. Returns raw binary image bytes with appropriate Content-Type and caching headers.

Example Request (Dynamic Card):
GET https://imagengine.grisma.info.np/api?title=Kathmandu-4+Election&subtitle=Gagan+Kumar+Thapa+Won&badge=2079+Election&theme=cyber&format=png&width=1200
Example Request (Remote SVG Ingestion):
GET https://imagengine.grisma.info.np/api?url=https%3A%2F%2Fraw.githubusercontent.com%2F...%2Flogo.svg&format=webp&width=800
POST

/api

Accepts raw SVG XML markup directly in the request body. Ideal for serverless workers and applications generating SVGs in-memory without a public URL. 

POST https://imagengine.grisma.info.np/api?format=png&width=1200
Content-Type: image/svg+xml

<svg width="1200" height="630" xmlns="http://www.w3.org/2000/svg">
  <rect width="1200" height="630" fill="#030712"/>
  <text x="600" y="315" fill="#38bdf8" text-anchor="middle" font-size="52">Live In-Memory Render</text>
</svg>

Parameters Reference

Parameter Type Default Description
url string — Full URL of the source SVG to fetch and rasterize. Must be URL-encoded and served over HTTP/HTTPS.
format string png Target raster format: png (lossless), jpg (compact), or webp (modern).
width number 1200 Output width in pixels (range: 100 to 2400). Aspect ratio is strictly preserved.
quality number 85 Compression quality for jpg and webp (range: 10 to 100).
Dynamic Card Mode Parameters
title string — Headline text. Automatically line-wraps across 1 to 3 lines with dynamic font scaling.
subtitle string — Secondary excerpt or summary text. Automatically wraps across up to 2 lines.
badge string Open Graph Ready Top pill label with glowing status dot.
theme string cyber Visual card color palette: cyber, emerald, sunset, midnight.

🌍 Multi-Tier Edge CDN Caching

ImageEngine dispatches explicit caching directives compliant with RFC 9213, Cloudflare Edge, and Vercel Edge Network: 

Cache-Control: public, max-age=31536000, s-maxage=31536000, stale-while-revalidate=604800, stale-if-error=86400
CDN-Cache-Control: public, max-age=31536000, stale-while-revalidate=604800
Vercel-CDN-Cache-Control: public, max-age=31536000, stale-while-revalidate=604800
Cloudflare-CDN-Cache-Control: public, max-age=31536000, stale-while-revalidate=604800
Surrogate-Control: max-age=31536000
ETag: "9b3c...f1a"
Vary: Accept-Encoding
Cold Cache Render (~12ms)

First-time generation. Resvg renders the SVG and populates edge data centers worldwide.

Edge Cache Hit (< 15ms)

Served directly from the nearest Cloudflare or Vercel PoP without executing serverless functions.

🛡️ Cloudflare WAF & Bot Protection Configuration

If your source SVG host (e.g. election.topnepali.com) is protected by Cloudflare Bot Fight Mode or strict WAF rules, it may block automated serverless fetches with a 403 Forbidden or CAPTCHA challenge.

Outgoing User-Agent:
User-Agent: ImageEngine/1.0 (+https://imagengine.grisma.info.np)
Recommended Cloudflare WAF Custom Rule:

In your Cloudflare dashboard under Security → WAF → Custom rules, create an allow/skip rule:

Expression: (http.user_agent contains "ImageEngine")
Action: Skip → WAF Managed Rules, Bot Fight Mode, Rate Limiting

2. JavaScript / TypeScript Helper Function

export function getOgImageUrl({
  title,
  subtitle = '',
  badge = 'Live',
  theme = 'cyber',
  format = 'png',
  width = 1200
}: {
  title: string;
  subtitle?: string;
  badge?: string;
  theme?: 'cyber' | 'emerald' | 'sunset' | 'midnight';
  format?: 'png' | 'jpg' | 'webp';
  width?: number;
}) {
  const params = new URLSearchParams({
    title,
    subtitle,
    badge,
    theme,
    format,
    width: width.toString()
  });
  return `https://imagengine.grisma.info.np/api?${params.toString()}`;
}

3. cURL CLI

# Generate social card
curl -o preview.png "https://imagengine.grisma.info.np/api?title=Breaking+News&subtitle=Live+Update&format=png"

# Convert external SVG
curl -o logo.webp "https://imagengine.grisma.info.np/api?url=https%3A%2F%2Fexample.com%2Ficon.svg&format=webp&width=600"

HTTP Status Codes

Status Meaning Description
200 OK Success Image successfully rasterized. Returns binary buffer with appropriate Content-Type.
304 Not Modified Cached Response matches client's If-None-Match ETag. Zero body bytes transferred.
400 Bad Request Invalid Payload Missing SVG content or unsupported URL protocol (must be HTTP/HTTPS).
413 Payload Too Large Exceeds Limit SVG payload exceeds 512 KB memory safeguard threshold.
502 Bad Gateway Upstream Error Remote SVG source URL failed to respond within 6 seconds or returned an HTTP error.
