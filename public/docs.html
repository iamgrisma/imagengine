API Reference

The ImageEngine API allows any web application to convert dynamic or static SVG graphics into high-resolution PNG, JPG, or WebP formats at edge speed.

GET /api

Renders and returns an image binary directly with standard Content-Type headers.

GET https://imagengine.grisma.com.np/api?url={ENCODED_SVG_URL}&format={png|jpg|webp}&width=1200

Query Parameters

Parameter Type Default Description
url string — Full URL of the source SVG to fetch and rasterize. Must be URL-encoded.
format string png Target raster format. Options: png, jpg, webp.
width number 1200 Target width in pixels (100 to 2400). Aspect ratio is strictly preserved.
quality number 85 Compression quality for jpg and webp (10 to 100).
title string — Built-in generator mode: Headline text.
subtitle string — Built-in generator mode: Subtitle text.
badge string — Built-in generator mode: Top pill badge label.

Integration Examples

1. HTML Open Graph Tag (for WhatsApp & Facebook)

<meta property="og:image" content="https://imagengine.grisma.com.np/api?url=https%3A%2F%2Felection.topnepali.com%2Fapi%2Fog.svg%3Ftitle%3DKathmandu-4&format=png" />
<meta property="og:image:width" content="1200" />
<meta property="og:image:height" content="630" />
<meta property="og:image:type" content="image/png" />

2. cURL

curl -o preview.png "https://imagengine.grisma.com.np/api?title=Hello+World&format=png"

3. React / Next.js / Astro Component

export function getOgImageUrl(svgPath) {
  const base = 'https://imagengine.grisma.com.np/api';
  return `${base}?url=${encodeURIComponent(svgPath)}&format=png`;
}

Edge CDN Caching Specifications

Every response sends Cache-Control: public, max-age=604800, s-maxage=31536000, stale-while-revalidate=86400. The edge caches the generated file for 1 full year globally. Repeat requests load in under 15 milliseconds.
